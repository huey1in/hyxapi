# 接口参考

| 文件 | 范围 |
| --- | --- |
| [api.json](api.json) | 账户、令牌、渠道等管理接口 |
| [relay.json](relay.json) | 模型列表、协议转发、图片和视频任务接口 |

两份文件均为 OpenAPI 3.0.1，可导入支持该格式的 API 工具；使用部署站点地址作为服务器地址。它们是手工维护的参考，并未覆盖所有业务接口。

路由注册与权限以 [`router/`](../../router) 为准，动态任务接口还由插件声明。工单、支付等业务说明见[文档目录](../README.md)，不要把模型 API Key 当作后台管理凭证使用。

接口变更时同步核对请求方法、路径参数、请求体、响应结构和认证方式。新增或删除渠道、模型协议或插件时，检查对应描述；示例只使用占位凭据。
