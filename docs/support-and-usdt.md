# 工单与自托管 USDT 收款

## 工单权限

个人入口为 `/tickets`，仅列出当前用户提交的工单；后台“工单管理”入口为 `/console/tickets`，从客服等级开始开放。详情链接分别为 `/tickets?ticket=<id>` 和 `/console/tickets?ticket=<id>`。数据库迁移自动创建 `tickets`、`ticket_messages`；不需要手动建表。

| 角色 | 权限 |
| --- | --- |
| 普通用户（1） | 创建工单、查看和回复自己的工单、关闭或重新打开自己的工单 |
| 客服（5） | 上述权限，以及查看待认领工单、认领工单、处理分配给自己的工单、添加内部备注 |
| 管理员（10） | 查看、处理和指派全部工单，在普通用户与客服等级之间调整低等级用户 |
| 超级管理员（100） | 管理员权限，以及管理员角色和站点收款设置管理 |

在“用户管理 → 新建 / 编辑用户 → 角色”中统一选择权限等级：用户、客服、管理员、超级管理员。管理员只能调整低于自己的等级；超级管理员账号保留保护，不能在此降级或新授予。角色变更通过用户更新接口提交，需要安全验证并使旧登录会话失效；降至管理员以下会清除管理员权限覆盖。客服没有用户管理、渠道、其他用户密钥、管理员审计页面或系统设置权限。

个人列表使用 `GET /api/tickets`，处理队列使用 `GET /api/tickets/manage`；后者在服务端校验客服及以上角色，并限制客服只能访问自己的、待认领或分配给自己的工单。详情、回复和内部备注继续独立校验归属及处理权限。

工单状态包括待处理、待用户回复、已解决和已关闭。用户回复会重新进入待处理状态，公开的客服回复会进入待用户回复状态。已关闭的工单须重新打开后回复。内部备注仅当前获授权的处理人员和管理员可见；工单创建者不能通过接口读取内部备注。指派、优先级和状态变更保留历史，客服操作进入管理员审计日志。当前支持文本，不包含附件上传。

## Epusdt 部署（不使用 Docker）

本集成面向 [Epusdt v2.0.0](https://github.com/GMWalletApp/epusdt/releases/tag/v2.0.0)，使用原生 GMPay 的 HMAC-SHA256 协议，不兼容 v1 的 GMPay MD5 签名。网关以独立进程部署，收款地址配置在网关中，HyxAPI 不存储钱包私钥或助记词。

1. 从该发布页下载匹配系统的二进制包及 `SHA256SUMS`，校验后解压到独立目录。Windows x64 对应 `epusdt-2.0.0-windows-amd64.zip`；Linux x64 对应 `epusdt-2.0.0-linux-amd64.tar.gz`。
2. 在解压目录运行 `./epusdt http start`；Windows 使用 `./epusdt.exe http start`。通过安装向导设置管理员和存储。完整步骤参见[官方手动部署文档](https://epusdt.com/zh/guide/installation/manual)，其中旧版本示例需替换为 v2.0.0。
3. 为网关配置独立 HTTPS 域名，例如 `https://pay.example.com`，反向代理到网关进程。配置所选链的 RPC、USDT 代币和自己的收款地址，确认网关可正常监听链上转账。链上手续费和 RPC 服务费用取决于实际网络与服务配置。
4. 在网关创建商户 API key，取得 `pid` 与 `secret_key`。

## HyxAPI 收款设置

超级管理员进入“系统设置 → 平台 → USDT（自托管 Epusdt）”，填写：

| 设置 | 示例 / 用途 |
| --- | --- |
| `usdt.gateway_url` | 网关 HTTPS 根地址，不能带账号、查询参数或 fragment |
| `usdt.merchant_id` | 网关生成的商户 `pid` |
| `usdt.api_key` | 商户 `secret_key`；保存后不回显 |
| `usdt.network` | 默认 `tron`，对应 TRON/TRC20；须与网关钱包及 USDT 配置一致 |
| `usdt.min_topup` | 最低充值金额，默认 5 USD，正整数 |
| `usdt.enabled` | 最后启用，默认关闭 |

站点在 `/setup` 保存的地址必须是外网可访问的 HTTPS 地址。网关回调：`POST https://<站点域名>/api/usdt/notify`。回调地址由后端生成，不能使用浏览器传入的地址替换。

充值以 USD 计价，1 USD 对应 1 USD 的站内额度；不套用其他渠道的人民币单价、分组倍率或充值折扣。USDT 实际数量由网关报价确定，并完整显示所有小数位。付款弹窗显示固定网络、地址、金额和有效期，不提供切换币种；二维码仅编码地址。用户可从“充值记录 → 付款详情”恢复订单。

后端核对 HMAC、商户、订单号、网关最终订单、USD/USDT、网络、地址、完整数量和链上交易号后才入账。余额与订单状态在同一事务中更新，额度按建单时的快照入账。重复回调不会重复增加余额，同一链上交易号不能结算多个订单；管理员不能跳过验证手动完成 USDT 订单。

关闭收款仅阻止新建订单，已有订单仍可回调。待处理订单结清前保留原商户密钥及网关地址；不要删除网关订单或清空密钥。网络错误、余额超限等会返回非成功响应，由网关重试；金额不足、转错网络、过期转账需通过工单核查，不自动入账。
