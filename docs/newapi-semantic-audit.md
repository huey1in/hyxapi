# New API 最终语义复核与验收

## 复核中补齐的行为

- **设置与下载**：Claude 默认输出限制拒绝负数、分数及非法结构，允许显式零；Gemini 校验有效安全阈值。Worker 配置实际传入下载调用，默认限制目标为 HTTPS，遵循 SSRF 配置，阻止携带密钥的请求重定向；直接下载使用受保护客户端。修复 `TaskPublicAddress` 保存后未更新运行时值。
- **计费与连接**：原生 `cache_write_tokens` 进入结算，避免与旧缓存字段重复累计；OpenRouter 仅在默认倍率及对应协议语义下推算缺失的缓存创建量，自定义价格、按次和表达式不参与推算。编辑、删除代理仅退役相关连接池；`RELAY_RESPONSE_HEADER_TIMEOUT` 仅限制等待响应头。
- **限流与流式状态**：成功请求限流在请求执行期间预留名额，失败释放，HTTP 200 的失败流也不计成功。通用 Redis 固定窗口改为原子脚本，修复并发超额、过期时间、错误策略及 `Retry-After`；Responses SSE/WebSocket 传递终止状态。
- **多密钥**：未知密钥不再误操作第一个密钥；状态更新只写所属字段。密钥耗尽会同步停用渠道及路由能力，恢复密钥可重新启用；明确手动停用保持有效，旧版本页面的操作不能覆盖新密钥状态。
- **SQLite 套餐**：旧 `INTEGER PRIMARY KEY` 会复用删除的套餐 ID，与保留的订阅历史发生混淆。事务迁移保留未知列、约束、索引及触发器，启用 `AUTOINCREMENT`，序列覆盖现存套餐和历史订阅、订单、兑换码引用。带自定义外键的表会明确拒绝自动重建，避免级联删除；迁移失败回滚。历史上已经发生的错误引用不能凭迁移自动判断归属。
- **插件市场**：索引及文件下载的 HTTP 错误使用可翻译的状态信息；失败或校验不符的文件不会打开安装预览。

测试中出现过旧标签定位、复用测试凭据错误，以及一次已记录 403 后的 Windows 连接重置；修正测试脚本或完整重跑后通过。SQLite 套餐历史冲突属于实际问题，已修复并增加回归覆盖。
